# Multi-Agent AI System

A production-ready **Multi-Agent AI System** built with the MERN stack and a scalable **microservices architecture**. The platform combines **LangGraph, LangChain, RAG, Qdrant, Redis, and AI tool calling** to build intelligent agents capable of retrieving information, processing documents, using external tools, and delivering real-time streaming AI responses.

The project is fully containerized with **Docker** and designed for scalable deployment on **AWS**, with secure JWT authentication, REST APIs, document processing, caching, and a modern React frontend powered by Redux Toolkit.

### Key Technologies

* MERN Stack — MongoDB, Express.js, React.js, Node.js
* Microservices Architecture
* LangGraph & LangChain
* Retrieval-Augmented Generation (RAG)
* Qdrant Vector Database
* Redis Caching
* AI Tool Calling
* Streaming AI Responses
* JWT Authentication
* File Upload & Document Processing
* REST APIs
* Redux Toolkit
* Docker
* AWS Deployment
